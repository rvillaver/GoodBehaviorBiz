Done = real thing working per [[project-profile]] + shown evidence + user confirmation; never self-declare. Canonical
wording: the principles home (CLAUDE.md, "The one rule"). For GoodBehaviorBiz specifically, a surface is not "guarded"
until it shows a live block + the matching audit entry. **Why:** the recurring failure is collapsing a whole task to
one cheatable proxy (a passing test, a wired-but-unexercised guardrail).
